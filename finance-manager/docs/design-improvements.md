# UI / UX 与产品优化记录

场景：自己或家庭使用。按 P0 → P1 → P2 实现；前端与用户提供的 FastApi 后端均已接入。

## 已实现

| 优先级 | 项目 | 实现结果 |
| --- | --- | --- |
| P0 | 数字与数据状态可信 | 汇总及列表区分加载、失败、成功空数据和缓存；失败可重试，缓存注明更新时间；没有成功数据时不显示零余额或结清结论。 |
| P0 | 账单目标准确 | 首页及账单页传递 transactionId；指定记录不存在时提示重新选择，确认前保留目标；不替换成另一笔。 |
| P0 | 账本与统计口径 | 资金指标改为“可分配收入”“待关联账单”，不冒充家庭总资产，注明范围；线上/本地缓存和读取请求按连接隔离；禁止写入超时后跨账本自动重试。 |
| P0 | 日期 | 收入支持到账日期与归属月份；账单支持发生日期，补录进入真实月份，迁移保留旧日期并标记估算。 |
| P1 | 一套账单筛选 | 全部、待处理、未核销、部分核销、已结清统一控制列表，月份从全部记录生成；筛选无结果提示清空条件。 |
| P1 | 操作上下文 | 搜索、状态、月份、类型与排序保存在 URL；切页保存返回位置；月度复盘进入账单明细携带月份，超过 14 天提醒携带年龄与状态条件。 |
| P1 | 紧凑页面与手机导航 | 缩短公共页头与页面介绍，统计采用紧凑卡片；手机底部五个导航均可见，加入跳转到主要内容入口。 |
| P1 | 核销流程 | 桌面三列列表独立滚动；手机选账单、选收入、确认金额三步；限制未结金额、收入余额和两位小数；确认按钮避开底部导航。 |
| P1 | 交易快速录入 | 默认先看交易记录，分析放独立标签；新增默认核心字段，详细复盘可展开；长表单内容滚动，保存操作始终可达；错误在操作区可见。 |
| P2 | shadcn 规范 | 增加 components.json，CLI 识别为 new-york / Radix / Tailwind v3；复用 Card、Alert、Empty、Field、ToggleGroup、Tabs、ScrollArea、AlertDialog 及语义主题变量。 |
| P2 | 可访问性与文案 | 表单标签关联控件、金额错误关联描述、图标按钮命名、选中状态及导航语义、取消时重置草稿；统一中文收入与账单术语，更新标题、图标及文档语言。 |
| P2 | 常用与每月账单 | 当前设备保存最多 20 条模板，按账本连接隔离；每月需确认后录入，成功后停止本月提醒；设置中支持按标题合并导入与删除。 |
| P2 | 导出 | 当前筛选账单 CSV（含公式转义）、完整快照 JSON（含原始字段、核销历史、收入、交易、分类、模板），可原子恢复到空账本；读取失败时不生成部分导出文件。 |
| P2 | 加载 | 复盘与交易分析页面按需加载，首页无需预先加载图表。 |

参考 [官方 shadcn skill](https://ui.shadcn.com/docs/skills) 与 [SKILL.md](https://github.com/shadcn-ui/ui/blob/main/skills/shadcn/SKILL.md)。保留项目的 Tailwind v3 和 Radix API。

## 已补齐的产品能力

- **生活支出分类**：内置餐饮、居家、交通等，设置中可新增、重命名、停用；账单录入、编辑、筛选、CSV 和月度图表同步支持，停用不删除历史。
- **个人消费一次完成**：选择已到账收入，创建消费并全额关联资金；金额与余额双重校验，失败回滚，历史可撤销。
- **完整备份恢复**：版本 2 数据库快照，不截断分页；预检后确认，拒绝覆盖非空账本，重复导入幂等，恢复失败整体回滚。
- **手机长表单**：账单、编辑、交易及设置的内容滚动与底部操作分离，金额确认与关闭入口保持可达。
- **旧版兼容**：按账本能力接口开放新功能；旧版连接继续使用已有字段和导出方式。

接口、迁移及部署要求见 [后端契约](backend-contract.md)。

## 验证

- `npm test`：17 个测试文件、48 项通过。新增回归覆盖指定账单、资金不足、非法金额、不存在的 ID、接口失败、跨账本缓存、超时不重放、筛选上下文、发生日期持久化接入、分类筛选、一次支付余额校验、分页完整性、备份恢复预检与旧版能力兼容、快速交易、模板及 CSV。
- `npm run lint`、`npm run build`：通过。构建仍提示主包超过 500 KB，图表已拆成按需加载的独立资源。
- 生产构建：通过五页加载、手机宽度和分析图表分包的冒烟检查。
- Chromium 浏览器：1440 × 1000、390 × 844、320 × 740；五页无水平溢出，页面图标按钮有名称，未捕获运行时错误。
- 浏览器交互：账单跳转、已结清筛选、返回时恢复搜索、月份衔接、超额金额禁用、不存在的账单不替换、草稿重置、分析标签、快速交易、JSON 导出和模板导入均通过。
- 数据状态：五页接口失败时不显示无依据的零金额；真实空账本仍显示真实零值和首次录入入口。
- 手机核销：30 笔账单时仍可直接进入确认；确认按钮完整位于底部导航上方。
- 相同示例数据下，390px 手机第一笔账单标题从原来的约 1781px 提前到 417px；公共页头从约 325px 缩短到 69px。
- 后端 `pytest`：43 项通过，覆盖发生日期、月度与存量统计、分类历史、Decimal 金额、一次支付及撤销、完整备份、关联 ID 映射、重复导入、错误密钥、非空账本拒绝和写入失败回滚。
- 数据迁移：含部分核销历史的旧账本升级、回退与重新升级通过；MySQL 离线迁移 SQL 生成通过，真实 MySQL / TiDB 尚未执行。
- 开发与生产构建 + 真实本地 API + Chromium：自定义分类、补录 9 月消费、一次支付后的余额、按分类复盘、JSON 快照、恢复到另一个空账本、重复恢复以及模板分类重新匹配通过。

示例数据与模拟故障检查拦截写入；真实联调仅写入两个独立的本地 SQLite 测试账本。未修改线上账本。主入口构建资源约 632 KB（gzip 200 KB），图表及分析页面已独立加载，仍有 500 KB 分包提示。
